# Lachesis Foundation Context

This task records the source material that defines the initial Lachesis
product. `prd.md` is the curated product requirement document. The detailed
source material is preserved under `research/source-documents/`:

| Source | Trellis use |
| --- | --- |
| `simulation-engine-design.md` | Simulation boundaries, world state, and reproducibility. |
| `data-model-and-api.md` | Core data contracts and API design. |
| `ux-and-interaction.md` | User workflows and presentation constraints. |
| `delivery-roadmap.md` | Milestones, validation, and delivery risks. |
| `decision-log.md` | Confirmed MVP decisions. |
| `mirofish-retrofit-plan.md` | Legacy-system migration and reuse analysis. |

The project-level, reusable specification lives in
`.trellis/spec/lachesis/`. Future implementation tasks should reference its
index in their implementation and review context.
