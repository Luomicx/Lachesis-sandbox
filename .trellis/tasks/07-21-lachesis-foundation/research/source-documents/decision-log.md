# Lachesis 已确认决策

本文档记录通过产品校准确认的 MVP 约束。除非产生新的正式决策，否则实现、测试和文案均以这些结论为准。

| ID | 决策 | 状态 |
| --- | --- | --- |
| D-001 | 首版面向中国大陆、面临考研和就业选择的本科生。 | 已确认 |
| D-002 | MVP 覆盖考研、多个具体 Offer、考研与工作比较、考研失败回退。 | 已确认 |
| D-003 | 用户选择不超过五年的时间跨度；前 12 个月按月、之后按季度。 | 已确认 |
| D-004 | 读研路径使用冲刺、匹配、保底的院校/专业分叉。 | 已确认 |
| D-005 | GPA/排名、预算、家庭支持等个人基线字段为必填，建模官负责预填和追问。 | 已确认 |
| D-006 | 录取概率、收入和职业发展速度都以带来源的模拟区间表达。 | 已确认 |
| D-007 | 用户与运营人员均可上传公开数据；用户数据只影响个人案例，审核官方数据才能成为全局默认。 | 已确认 |
| D-008 | 网络检索内容必须有来源链接、发布日期和适用年份，才可参与结果计算。 | 已确认 |
| D-009 | 生活和职场关系角色自动生成，无需运行前确认，首版不提供手动编辑。 | 已确认 |
| D-010 | 关系 Agent 只能影响受规则限制的机会概率，不能直接决定录取、升职或收入。 | 已确认 |
| D-011 | 首版取消 2.5D 动画，采用宏观路径树、生命线、关系网络、对话和分叉。 | 已确认 |
| D-012 | 用户只能修改可控前因，不能直接覆写结果。 | 已确认 |
| D-013 | 保存报告生成不可变快照，支持不含敏感原始资料的 PDF 导出。 | 已确认 |
| D-014 | 首版需要账号但只支持单设备；设备丢失或更换后数据不可恢复。 | 已确认 |
| D-015 | 即使没有真实 Offer，用户也可以建立手动填写的假设工作路径。 | 已确认 |
| D-016 | 缺乏匹配的合格官方数据时，标记数据不足，不生成伪精确录取概率。 | 已确认 |
| D-017 | 个人资料只能发送至受信任且承诺不用于训练的模型服务。 | 已确认 |
| D-018 | 时间跨度固定为 1 年、3 年、5 年。 | 已确认 |
| D-019 | 每条路径的运行规模固定为快速 10、标准 20、深入 50 个世界。 | 已确认 |
| D-020 | MVP 仅覆盖计算机/软件/AI 相关专业与岗位。 | 已确认 |
| D-021 | MVP 不做实时全网爬取，只接收用户上传和运营人工审核的官网公开资料。 | 已确认 |
| D-022 | 生涯建模官与世界角色严格分离，后者只在仿真开始后对话。 | 已确认 |
| D-023 | 每项报告结论必须拥有且只拥有一种来源标签。 | 已确认 |
| D-024 | 即使资料带有官网链接，进入全局默认数据集前仍须人工审核。 | 已确认 |
| D-025 | MVP 不显示总分、路径排名或推荐按钮，只提供可追溯的人生预演。 | 已确认 |
| D-026 | MVP 官方数据目录仅覆盖 20 个计算机相关研究生项目和 6 个核心就业城市。 | 已确认 |
| D-027 | 报告首页固定展示模拟免责声明，不构成录取或职业结果承诺。 | 已确认 |
| D-028 | 世界运行一律异步，显示完成数、版本和失败种子，不承诺实时动画或秒级完成。 | 已确认 |
| D-029 | 假设 Offer 固定标为“假设路径”，不得与真实 Offer 混用可信度标签。 | 已确认 |
| D-030 | 项目与城市目录由运营人员配置并版本化，目录外对象不能获得量化概率。 | 已确认 |
| D-031 | 世界角色只提供仿真完成后的只读对话，改变未来必须创建分叉。 | 已确认 |
| D-032 | 世界角色只接收最小化派生属性，不接收原始敏感资料。 | 已确认 |
| D-033 | 所有影响指标的 LLM 事件必须通过规则校验并关联规则、输入或证据。 | 已确认 |
| D-034 | 一个案例最多同时比较 4 条路径。 | 已确认 |
