# 交付规格

## 顺序

1. 本地配置、依赖和 zep_adapter 健康检查。
2. 案例资料导入、建模官、档案确认和本地 RAG。
3. 项目/城市 catalog、路径和数据不足状态。
4. Mesa + SimPy 最小世界：考研匹配院校与假设 Offer，运行十个一年世界。
5. 生命线、报告、关系网络、分叉和脱敏 PDF。

## 完成定义

- 根目录 MiroFish 不作为运行依赖。
- 不需要 Zep Cloud API Key。
- 资料与证据可追溯、案例隔离、数据可删除。
- 无总分、排序或推荐。
- 所有影响指标的事件都有规则/输入/证据关联。
- 目录外学校或城市不产生伪精确概率。
