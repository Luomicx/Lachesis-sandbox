# 交付规格

## 顺序

1. 本地配置、provider-neutral 知识库门面和离线健康检查。
2. 案例资料导入与档案确认：先保存案例私有原始附件、允许手动分次补全档案，
   并在确认前校验完整基线；随后再实现文件解析、建模官和本地 RAG。
3. 项目/城市 catalog、路径和数据不足状态。
4. Mesa + SimPy 最小世界：考研匹配院校与假设 Offer，运行十个一年世界。
5. 生命线、报告、关系网络、分叉和脱敏 PDF。

## 完成定义

- 根目录 MiroFish 不作为运行依赖。
- 不需要 Zep Cloud API Key。
- 默认知识库不依赖 Neo4j、Qdrant、embedding 或外部网络服务。
- 原始附件摄入阶段不解析文件、不 OCR、不调用 LLM，且附件不得进入仿真输入、
  世界角色上下文或全局 catalog。
- 资料与证据可追溯、案例隔离、数据可删除。
- 无总分、排序或推荐。
- 所有影响指标的事件都有规则/输入/证据关联。
- 目录外学校或城市不产生伪精确概率。
